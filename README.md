# ドット爆破

写真をブロックの立体にして、こぶしや武器でぶっ壊すブラウザゲームです。

## 遊び方

▶ **今すぐ遊ぶ: https://planet-vs-planet.github.io/dot-bakuha/**

1. 「画像をえらぶ」から好きな写真・画像を選ぶ（選ばなくてもサンプルの惑星で遊べます）
2. 画像がドットの立体になります
3. 下の武器欄から武器を選んで、画面をタップ／クリックして壊す

### 武器（全7種）
| # | 武器 | 操作 |
|---|------|------|
| 1 | こぶし | タップでパンチ、長押しで連続パンチ |
| 2 | ロケット | タップした場所に発射 |
| 3 | マシンガン | 長押しで連射 |
| 4 | ハンマー | タップで叩き潰す |
| 5 | いかずち | タップした場所に落雷 |
| 6 | いん石 | タップした場所に隕石 |
| 7 | レーザー | 長押しでなぞって溶かす |

数字キー 1〜7 でも武器を切り替えられます。ホイールでも切替可。

### 設定
- **向き / くるくる回す**：立体の角度を変える・自動回転
- **いりょく（小・中・大）**：破壊力の大きさ
- **大きさ**：立体の表示サイズ（40%〜250%）
- **背景を消して形だけ立体にする ON/OFF**：写真の背景を自動で消して被写体だけ立体化
- **おと ON/OFF**

## 技術
- 単一の `index.html` だけで動作（Three.js を CDN から読み込み）
- 画像はブラウザ内だけで処理され、サーバーに送信されません
- スマホ・PC 両対応

## ローカルで開く
`index.html` をブラウザで開くだけで遊べます。インターネット接続は Three.js / フォントの読み込みに必要です。
